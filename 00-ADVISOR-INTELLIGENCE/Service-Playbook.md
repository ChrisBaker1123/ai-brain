# Service Playbook

Step-by-step delivery framework. DLK is the template engagement — every future client follows this structure.

## Pre-Engagement

1. **Discovery call** (30 min): Understand firm, pain points, tech stack, team roles
2. **Proposal**: Setup fee + monthly retainer, scope of initial workflows
3. **Engagement letter**: Signed before any work begins ([[Engagement-Letter-Template]])
4. **Access requests**: Salesforce user account, tool credentials (secure handoff)

## Month 1: Foundation

### Week 1 — Audit & Discovery
- [ ] Individual interviews with each team member (15-20 min)
- [ ] Document each person's daily workflow, pain points, wish list
- [ ] Full Salesforce audit ([[Salesforce-Audit-Template]])
- [ ] Map entire tech stack and data flows
- [ ] Deliver AI Usage Policy draft for compliance review
- [ ] Identify top 3 workflows by impact × feasibility

### Week 2 — Build Workflow #1
- [ ] Design and spec the highest-priority workflow
- [ ] Build in Salesforce / Python / appropriate tool
- [ ] Test with real (non-client) data
- [ ] Demo to workflow owner for feedback
- [ ] Iterate based on feedback

### Week 3 — Build Workflow #2 + Deliver WF1
- [ ] Deploy Workflow #1 to production
- [ ] Design and build Workflow #2
- [ ] Begin data collection for any research-based workflows
- [ ] Deliver first outputs (e.g., prospecting intelligence report)

### Week 4 — Build Workflow #3 + Training
- [ ] Deploy Workflow #2
- [ ] Build Workflow #3
- [ ] Group training session (1 hour, all team members)
- [ ] Individual follow-ups for specialized workflows
- [ ] Deliver Month 1 Report ([[Monthly-Report-Template]])
- [ ] Plan Month 2 priorities with client

## Monthly Retainer (Month 2+)

Each month includes:
- 1 new workflow build or significant enhancement to existing
- Tool and AI landscape updates (what's new, what to adopt/drop)
- Salesforce maintenance and optimization
- Ad-hoc support (unlimited calls/texts)
- Monthly deliverable report

### Monthly Cadence
- **Week 1**: Review last month's metrics, plan current month's workflow
- **Week 2-3**: Build and test new workflow
- **Week 4**: Deploy, train, deliver monthly report

## Workflow Prioritization Framework

Score each potential workflow on:
1. **Time saved** (hours/week): How much manual work does this eliminate?
2. **Error reduction**: Does this prevent compliance/billing/communication errors?
3. **Revenue impact**: Does this directly drive new business or retain clients?
4. **Feasibility**: Can we build it with current access and tools?
5. **Client excitement**: Does the client actually want this?

Prioritize by: (Time saved × 2) + Error reduction + (Revenue impact × 3) + Feasibility + Client excitement

## Quality Standards

- Every workflow has a written Spec.md before building
- Every workflow is tested before deployment
- Every workflow has a rollback plan
- Every client-facing output is reviewed by the advisor before sending
- Every data access point is documented in the compliance file
- Monthly report includes: what was built, metrics, next month plan
