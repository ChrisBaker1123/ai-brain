# Competitive Landscape

> Updated monthly. Last update: 2026-03-24.

## Direct Competitors

| Tool | Focus | Pricing | Weakness vs Us |
|------|-------|---------|---------------|
| **Hazel** (Altruist) | Meeting notes, CRM integration | ~$500/mo | Limited to Altruist clients, no custom workflows |
| **Jump** | Portfolio analytics, reporting | ~$1,000/mo | Analytics only, no workflow automation |
| **Zeplyn** | Meeting transcription, CRM notes | ~$200/mo | Transcription only, no strategic consulting |
| **Agentforce** (Salesforce) | AI agents within Salesforce | $2/conversation | Requires Enterprise+, complex setup, no human advisor |
| **Pulse360** | Meeting notes, client summaries | ~$300/mo | Notes focus, not full-practice AI consulting |
| **FP Alpha** | Estate/tax document analysis | ~$500/mo | Document analysis only, narrow scope |
| **CogniCor** | Virtual assistant for advisors | Custom | Enterprise-focused, not boutique RIA friendly |

## Why We Win

None of these are a **fractional AI officer**. They're all tools. We're a person + tools.

| Dimension | Tools | Advisor Intelligence |
|-----------|-------|---------------------|
| Setup | Self-serve, figure it out | We set it up for you |
| Customization | Generic workflows | Built for your specific firm |
| Training | Documentation/videos | In-person, per-person |
| Updates | You track releases | We tell you what matters |
| Support | Ticket system | Call/text Cri directly |
| Compliance | Built-in (maybe) | Custom AI usage policy + ongoing review |
| Scope | One domain (notes, or analytics, or planning) | Full practice coverage |

## When to Recommend Competitors

Sometimes the right answer is to recommend a specific tool as part of our engagement:

- **Hazel**: If client is on Altruist → recommend Hazel for meeting notes, we handle everything else
- **Pulse360**: Good meeting notes tool → can be part of the stack we manage
- **FP Alpha**: If client does heavy estate work → recommend for document analysis
- **Otter.ai / Fireflies**: For meeting transcription → we integrate output into workflows

We're the orchestrator, not the replacement. We tell clients which tools to use AND how to use them.
