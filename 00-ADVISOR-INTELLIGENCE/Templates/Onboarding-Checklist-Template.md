# Client Onboarding Checklist

> Week-by-week onboarding template. Customize per client.

## Pre-Start

- [ ] Engagement letter signed
- [ ] Setup fee received
- [ ] Dedicated Salesforce user account created for Cri
- [ ] Tool access credentials securely shared (password manager)
- [ ] Team member list and contact info received
- [ ] Existing documentation/SOPs shared

## Week 1: Audit & Discovery

- [ ] Individual interviews (15-20 min each)
  - [ ] {{person_1}} — {{role_1}}
  - [ ] {{person_2}} — {{role_2}}
  - [ ] {{person_3}} — {{role_3}}
  - [ ] {{person_4}} — {{role_4}}
  - [ ] {{person_5}} — {{role_5}}
- [ ] Document each person's daily workflow, pain points, wish list
- [ ] Salesforce audit complete ([[Salesforce-Audit-Template]])
- [ ] Map full tech stack and data flows
- [ ] AI Usage Policy draft delivered to CCO
- [ ] Top 3 workflows identified and prioritized
- [ ] Week 1 summary sent to client

## Week 2: Build Workflow #1

- [ ] Workflow #1 spec written and approved by owner
- [ ] Build complete
- [ ] Test with sample data
- [ ] Demo to workflow owner
- [ ] Iterate based on feedback
- [ ] Begin Workflow #2 spec

## Week 3: Build Workflow #2 + Deliver WF1

- [ ] Workflow #1 deployed to production
- [ ] Workflow #2 build complete
- [ ] First deliverable from WF1 sent (if applicable)
- [ ] Begin Workflow #3 spec

## Week 4: Build Workflow #3 + Training

- [ ] Workflow #2 deployed
- [ ] Workflow #3 build complete or in progress
- [ ] Group training session (1 hour, all team)
- [ ] Individual follow-ups for specialized workflows
- [ ] Month 1 Report delivered ([[Monthly-Report-Template]])
- [ ] Month 2 priorities agreed with client
