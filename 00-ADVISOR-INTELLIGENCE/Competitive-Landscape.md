## When to Recommend Competitors

Sometimes the right answer is to recommend a tool as part of our engagement:

- **Zocks**: DLK's recommended meeting tool (no-recording = compliance-first)
- **Jump**: If client wants pre-meeting prep and doesn't mind recording
- **Hazel**: If client is on Altruist custody
- **Pulse360**: Cost-effective meeting docs for larger teams (flat pricing)
- **FP Alpha**: If client does heavy estate/tax work

We're the orchestrator, not the replacement. We tell clients which tools to use AND how to use them together.
